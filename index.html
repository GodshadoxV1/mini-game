    ♞PICHESSDUEL ENTRE JOUEURS
    ⚔ DUELS RÉELS

    Défiez un autre joueur.

    Deux personnes sur un même appareil. Un duel classé utilise deux comptes Pi Games distincts pour enregistrer le résultat et attribuer des points Elo aux deux joueurs.

    🏆 Duel classé

    Le joueur connecté joue les blancs. Votre adversaire se connecte brièvement pour confirmer son identité, puis joue les noirs.

    🎮 Duel amical

    Jouez à deux sans second compte. Cette option est idéale pour une partie rapide entre amis, mais n’affecte pas les Elo.

    ✓ Deux Elo distincts pour les bots et les joueurs✓ Profil public avec badges, titres et statistiques✓ Résultat classé sans possibilité d’annuler les coupsℹ️ Mode local : pas de matchmaking distant sans serveur en ligne
